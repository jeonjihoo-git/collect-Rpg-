### 알려진 한계 / 남은 오류 위험
- Unity 6 에디터에서 실제로 열어 본 적 없음 → 첫 실행 시 패키지 버전 조정(URP 17.0.x) 또는 소소한 API 경고가 나올 수 있음. 컴파일 검사는 Unity 2021.3 엔진 참조 기준이라 Unity 6 전용 경고는 잡지 못함.
- uGUI 는 스텁으로 컴파일 검사(실제 패키지 아님).
- 모델·애니메이션은 프리미티브 + 절차 포즈(플레이스홀더), 효과음은 절차 합성(플레이스홀더).
- 이펙트 오브젝트는 풀링 없이 생성/파괴(파티클만 풀) — 실기기 GC/발열 확인 필요.
- 신규 Input System 전용 프로젝트에 복사할 경우 키보드 입력은 `#if ENABLE_INPUT_SYSTEM` 분기로 처리하나 미검증.
