# LUMINA CHRONICLE — 개발 인수인계 패키지

**기준일** 2026-10-17

이 패키지는 기존의 **모바일 실시간 액션 수집형 RPG** 「루미나 크로니클」을 다른 ChatGPT/Claude Code/Unity 개발자·PC에서도 일관되게 재구축할 수 있도록 기존 GDD와 구현 이력에서 내용을 이전한 문서 모음입니다.

## 읽는 순서

1. `01_START_HERE.md` — 최신 게임 시스템 핵심 정책, 16명 로스터, 화면, 재구축 우선순위, 확정/미확정 표시.
2. `02_GAME_DESIGN_FULL.md` — 기존 **GDD v2.0 전체** Markdown 변환본. 총 25개 화면 상세 명세와 기초 공식 포함.
3. `04_MACHINE_RULES.json` — 핵심 목록 및 숫자 머신 리더블 데이터. `null`은 자료 미확정이라는 뜻.
4. `05_RESTART_PROMPT.md` — 새 AI/개발자에게 그대로 복사해 사용하는 시작 지시문.
5. `06_QA_CHECKLIST.md` — 실제 구현 및 회귀 검증 수용 기준.
6. `원본_GDD_v2.0_2026-10-17.docx`, `원본_개발현황_2026-10-17.docx` — 기존 편집용 공식 출처 문서.

**중요**: 이 패키지는 GDD·구현 이력과 개발 지시/데이터 번들입니다. **최신 실제 게임 소스코드, Unity 프로젝트, 3D 모델, 음원, APK는 포함하지 않습니다.** 웹 시제품 기능 또는 개발 대화의 테스트 통과 보고가 최신 완제품 실행 검증을 뜻하지는 않습니다. 예전 18개 캐릭터 일러스트 콘셉트도 새로운 16명 게임 로스터와 자동으로 병합하지 마세요.

**충돌 해결**: `01_START_HERE.md`에서 정리한 최신 확정 변경사항을 먼저 적용하고, 자세한 인터페이스는 `02_GAME_DESIGN_FULL.md`를 따른다. 수치가 불명확하면 임시값임을 표시해 최종 결정 전에는 확정 데이터로 병합하지 않는다.
