## 세계관과 시나리오 범위

배경 시안은 “부서진 별”, 천공 도시 “루미나”, 별의 계승자, 잊힌 별의 성소를 사용한다. 이 문구들은 초기 UI 테마에 반영된 세계관 시안이며, 1~90장 전체의 확정된 시나리오 본문이나 정식 고유명사 체계로 간주하지 않는다.

초기 웹 화면에서 확인된 스토리 예시는 제1장 「별이 잠든 땅」의 6개 노드와 제2장 「푸른 기억」의 일부 연결이다. 1~90장을 설계했다는 대화 이력이 있지만 장별 원문과 최신 데이터 테이블이 없으므로 복원 필요 작업으로 관리한다.

## 03-2. 전투 계산식과 기본값

아래 식과 숫자는 2026.09.27 통합 시스템 설계서의 “기준값”을 재수록한다. 캐릭터별 최종 SkillDef/WeaponTypeDef 값과 실제 애니메이션 타이밍이 확보되면 다시 조정한다.

타격 피해 = 사용 타입 공격력 × 모션 계수 × 스킬 레벨 배율 × (1 − 최종 방어 감소율) × 속성·치명타·스태거 등 상황 배율

K = 300 × (1 + 0.02 × 적 레벨), 유효 방어력 = D × (1 − 관통률), 방어 감소율 = max(0, 유효 방어력/(유효 방어력+K) − 방어력 무시%p). 관통과 방어력 무시는 중복 적용하지 않는다.

| **항목**             | **초기 기준값 / 조정 필요**                                                                    |
|----------------------|------------------------------------------------------------------------------------------------|
| **제한시간**         | 180초                                                                                          |
| **공명**             | 일반 공격 +4, 스킬 +10, 완벽 회피 +18, 태그 +3, 궁극기 사용 −100                               |
| **브레이크**         | 일반 100 / 하드 150 / 헬 220. 미피격 시 초당 3 회복. 브레이크 0에서 5초 스태거, 피격 피해 ×1.5 |
| **공격 기초 계수**   | 일반 1타 0.12 / 스킬 0.32 / 궁극기 0.90                                                        |
| **임시 조작 쿨타임** | 일반 0.58초 / 스킬 6초 / 태그 1초 / 회피 2.5초, 회피 무적 0.65초                               |
| **태그 효과**        | 남은 일반 공격 쿨타임 50% 감소(초기 설계). 캐릭터별 스킬 재사용 6초는 유지.                    |
| **목표**             | 일반 적 1체 8~15초 / 브레이크 1~2회 / 속성 반응 기여 15~25%                                    |

**전투 정합성** 물리/마법 공격 타입은 속성과 별도 데이터 필드다. 적 방어도 물리·마법을 분리한다. 기존 CP에 장비/돌파 값을 두 번 곱하지 않는다.

## 03-3. 자동전투 최신 채택 규칙

> • 자동전투 토글은 스테이지 선택 이후의 “파티 편성 화면”에서 설정한다. 전투 HUD의 이전 “자동 일반 공격” 토글은 구버전 UI다.
>
> • 플레이어가 한 번도 클리어하지 않은 스테이지는 자동전투를 사용할 수 없다. 클리어 여부는 ClearRecord(stageId)로 판정한다.
>
> • 자동전투는 일반 공격뿐 아니라 스킬·회피·궁극기의 자동 사용을 목표로 한다. 세부 AI 타겟팅/수동 개입 규칙은 미확정이다.
>
> • 편성 화면에는 잠금 사유, ON/OFF, 해당 스테이지의 클리어 기록을 보여준다. 전투 진입 후 불일치를 방지한다.
>
> • 현재 웹 시제품의 자동 일반 공격과 새 정책의 완성은 같지 않다. 실기기에서 각 명령의 발동을 개별 검증해야 한다.

## 04-3. 레벨 스탯 및 CP 원본 기준

공격력 = 기본 공격력 × \[1+0.045×(Lv−1)\], 체력은 0.06, 방어는 0.03 기울기. 돌파는 단계당 기초 스탯 +8%. 이는 초기 계산 축으로서 역할 가중치가 반영된 기초 스탯에 이중 적용하지 않는다.

CP = (최종 공격력×1.0 + 최종 체력×0.35 + 최종 방어력×0.5) × 파티 속성 반응 기대 보정(1.00~1.15). 원본의 임시 공식이며 권장 전투력 안내용으로만 사용한다. 실제 전투 승패를 CP로 강제하지 않는다.

## 07-3. 유물 옵션 생성·강화 규칙 \[확정 원칙\]

> • 유물 주옵은 부위별 고정 옵션 범주를 유지한다. 상세 수치표와 장갑 주옵(구판 공격력% vs 후속 치확/치피)은 최종 검토가 필요하다.
>
> • 부옵은 모든 유물 부위에서 공통 후보군 중 중복 종류 없이 초기 1~4개가 랜덤으로 붙는다.
>
> • 처음 부옵이 1개인 유물은 +15까지 강화하는 동안 신규 부옵 3개가 추가되어 총 4개에 도달한다.
>
> • 처음 부옵이 4개라면 새로운 종류를 부여하지 않고 기존 부옵 수치를 강화한다. 2~3개로 시작한 경우의 정확한 강화 단계별 성장 규칙은 확정 데이터가 필요하다.
>
> • 유물 던전의 난이도가 높을수록 고등급 유물의 획득 비중이 증가한다. 확률표·세트 효과·강화 실패/소모 비용은 확정되지 않았다.

**변경 고정** 유물 4부위 +15 구조를 신규 모든 화면과 저장 테이블의 기준으로 사용한다. 캐릭터별 임시 +5 장비 객체는 마이그레이션이 필요한 구스키마다.

# 08. 캐릭터/전용무기 소환 시스템

| **등급** | **기본 확률** | **비고**                                 |
|----------|---------------|------------------------------------------|
| **N**    | 70%           | 일반 소환                                |
| **R**    | 20%           | 일반 소환                                |
| **SR**   | 9%            | 일반 소환                                |
| **SSR**  | 1%            | 100회부터 확률 상승 / 200회까지 SSR 보장 |
| **UR**   | 0%            | SSR 진화 전용                            |

등급별 기본 확률은 N 70%, R 20%, SR 9%, SSR 1%이며 UR은 소환에서 나오지 않는다. SSR은 100회부터 확률이 증가하고 최대 200회 이내 등장하도록 하는 규칙만 확정되었다. 2026.09.27 문서의 매회 +2%p 기술은 산술 충돌이 있어 폐기한다. 2026.09.28 웹 시제품의 100~199회 임시 곡선(100회 1.05%, 199회 6%)은 정식 출시 공식이 아니다.

## 08-1. 픽업 실패 보정 \[2026.10.11 이후\]

> • 캐릭터 픽업에서 비픽업 SSR을 얻으면 다음 “SSR이 등장할 때” 해당 픽업 SSR을 확정 지급한다. 즉 다음 1회가 SSR 확정인 것은 아니다.
>
> • 전용무기 픽업도 같은 종류의 보정을 적용하되, 캐릭터 픽업과 카운터/이탈 보정 상태는 별도 관리한다.
>
> • N/R/SR 획득이나 재접속·일반적인 배너 전환으로 픽업 확정 플래그가 사라지지 않도록 한다.
>

>
> • 배너 기간, 개별 픽업확률, 카운터 이월 범위, 무기 배너의 독립 확률/천장 상세는 미확정으로 기록한다.

## 08-2. 소환 UI와 연출

캐릭터 SSR 획득 시 「황금 별자리 각성」, 전용무기 SSR 획득 시 「금빛 봉인 파괴」 연출이 최근 구현·검사되었다고 보고되었다. 결과 데이터 확정은 연출 재생보다 먼저 처리하고, 중복 클릭/재진입이 소환을 중복 실행하지 못하게 한다.

초기 체험용 소환 비용은 1회 부족분 별빛 결정 160, 1회/10회 버튼과 소환권 우선 사용이었다. 출시 비용 확정값이 아니며 유료·무료 소환권 및 배너별 교환 정책을 별도 설계해야 한다.
