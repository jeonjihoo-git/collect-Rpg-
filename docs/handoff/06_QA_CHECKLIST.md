# 루미나 크로니클 — 재개발 필수 QA 체크리스트

각 항목은 **통과/실패/미구현/검증불가**를 분리해 기록한다. AI가 작성한 코드가 존재한다는 사실만으로 `통과` 처리하지 않는다. 아래는 새 빌드의 테스트 목표이며, 이전 빌드의 합격 실적을 의미하지 않는다.

## 1. 실행/데이터 정합

- [ ] 클린 체크아웃/신규 PC에서 설치 가이드대로 빌드, 시작, 스테이지 진입 가능
- [ ] 16명 최신 로스터와 16개 무기 카테고리 조회 및 참조 누락 없음
- [ ] 보유 캐릭터와 과거 콘셉트 18인 데이터 혼용 없음
- [ ] 동일 캐릭터를 4인 파티에 중복 편성할 수 없음; 전투 중 KO 캐릭터로 교체 금지
- [ ] 전투 입력과 SFX/VFX 명중 이벤트 프레임이 일치하고 에러로그가 없음

## 2. 전투 손맛

- [ ] 일반공격·고유스킬·궁극기·회피·태그 사용 및 쿨타임/공명 소비 정상
- [ ] 이동 중 회피, 회피 무적구간, 퍼펙트 회피 보상, 브레이크 후 경직 판정
- [ ] 9속성과 물리/마법 구분, 13반응만 발동(바위+얼음은 보호막)
- [ ] 장검/단검/대검/쌍검/창/건틀릿/낫/도끼/활/석궁/총/런처/지팡이/마법책/스크롤/마법링 16종에 독립 공격 특징
- [ ] 활의 시위·화살, 총의 발포·탄착, 낫의 큰 호, 대검의 무게, 스크롤의 캐스팅 등이 청음으로 명확히 구별됨
- [ ] 모바일 스피커, 헤드폰에서 금속 징/종소리 일괄 재사용 문제가 없음

## 3. 자동전투

- [ ] 클리어하지 않은 스테이지는 편성 화면에서 자동전투 OFF 잠금과 사유 표시
- [ ] 클리어 기록이 생긴 뒤 동일 스테이지에 한해 자동전투 ON 활성화
- [ ] 전투 HUD의 구버전 기본공격 자동 토글을 최신 정책으로 오인하지 않음
- [ ] 자동공격/스킬/회피/궁극기 모두 사용 가능, 수동 개입/타겟팅 동작 명세 확정

## 4. 성장/경제/유물

- [ ] Lv.30 상한, 6돌파/60레벨, 3개 스킬 Lv.10 한도, 동일 캐릭터 중복 소비
- [ ] 전용무기만 무기 소환, 유물 4부위, 강화 +15 (구판 +5 금지)
- [ ] 부옵 초기 1~4종 종류 중복 없음; 1개 시작은 +15 때 4개; 4개 시작은 수치 강화
- [ ] 각 소비에 재고/한도/중복클릭 원자성, 음수 재화 불가
- [ ] 1회 스테이지 승리에 보상 1회; 첫 클리어/반복 보상/최고 별 분리
- [ ] 테스트 재화 지급 버튼은 개발/테스트 빌드에서만 허용

## 5. 가챠

- [ ] N70 / R20 / SR9 / SSR1 / UR0 기본 확률, 천장으로 변하는 확률은 별도 승인표 사용
- [ ] 100회 이후 확률 상승 및 200회까지 SSR 보장 (실제 수치표 승인 전 릴리스 금지)
- [ ] 캐릭터 픽업 이탈 시 **다음 SSR**은 픽업 확정
- [ ] 전용무기 픽업 이탈 보정은 캐릭터와 독립, 상시 배너에는 플래그 없음
- [ ] 재접속/10연속/배너 전환/픽업 SSR 수령 시 플래그 전이 정상
- [ ] 연출 재생/재진입/연타 시 재화 중복 차감·중복 지급 없음
- [ ] SSR 캐릭터와 무기 연출이 맞는 배너에서만 호출됨

## 6. UX/플랫폼/복구

- [ ] 캐릭터 상세 진입 때 상단 카드 리스트 없이 선택한 한 명의 전신 중심
- [ ] 25개 화면 중 구현/미구현 표시, UI 버튼이 실제 기능에 연결되어 있음
- [ ] 모바일 가로 화면, 안전영역/노치/텍스트/터치, 프레임과 발열 시험
- [ ] 강제 종료/재접속 후 보상·파티·확정 가챠 상태·ClearRecord 복구
- [ ] 로그인·백엔드·결제·협동/PvP는 실제 구현을 검증하기 전 '미구현'으로 표시
